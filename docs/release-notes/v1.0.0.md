# SafeSweep v1.0.0

SafeSweep is an open-source Windows storage cleaner designed around safety, transparency,
and user control. This is the first public release.

## Downloads

| File | Who it is for |
| --- | --- |
| **`SafeSweep-Setup-x64.exe`** | **Download this one if you are not sure.** Installs SafeSweep with a Start menu entry and an uninstaller. |
| `SafeSweep-Portable-x64.exe` | Runs without installing, from any folder. |
| `SafeSweep-x64.msi` | For IT administrators deploying with Group Policy, Intune or similar tools. |
| `SHA256SUMS.txt` | SHA-256 checksums of the files above. |

Requirements: Windows 10 or Windows 11, 64-bit. .NET is included; nothing else to install.

**Windows SmartScreen:** these files are not code-signed yet, so Windows may show
"Windows protected your PC" the first time. Click **More info**, check the file name, then
**Run anyway**. To verify a download, run
`Get-FileHash .\SafeSweep-Setup-x64.exe -Algorithm SHA256` in PowerShell and compare the
result with `SHA256SUMS.txt`.

## Highlights

- **Quick, Full and Custom scans** with three levels: Safe Clean (recreated automatically,
  pre-selected), Deep Clean (never pre-selected, quarantined first) and Manual Review (your
  decision, never deleted outright).
- **Every item explained**: location, size, dates, category, risk level, why it is removable
  and what happens afterwards.
- **Review tools** for large files, duplicate files (SHA-256 verified, one copy always kept),
  old and unused files, leftovers of uninstalled apps and empty folders.
- **Quarantine and restore** to the original location, with automatic purge after 30 days
  (adjustable).
- **Startup apps**, **scheduled Safe Clean**, **history**, **audit log** and **simulation
  mode**.
- Light and dark theme and a layout that adapts from small laptop screens to 1440p monitors.

## Safety

- Default-deny: automatic cleaning is limited to known cache and temporary locations.
- Windows, Program Files, installed programs, drivers, boot and recovery data, credentials,
  browser passwords and cookies, wallets and keys, version-control folders, game libraries,
  cloud-synced folders and your personal folders are protected.
- Every path is normalised and checked when the scan runs and again right before deletion.
  Junctions, symbolic links, hard links, 8.3 short names, `..` tricks and files that changed
  since the scan are all refused or skipped.
- SafeSweep's own install folder and executable are protected, including portable copies.
- SafeSweep runs with normal rights and asks for administrator rights only when you choose
  to clean a system location.

Found a way to make SafeSweep delete something it should not? Please report it privately:
see [SECURITY.md](https://github.com/trxxst/SafeSweep/blob/main/SECURITY.md).

## Known limitations

- Releases are not code-signed yet, so SmartScreen warns on first run (see above).
- English only.
- Leftover detection is heuristic. Portable programs have no uninstall entry and can look
  uninstalled; leftovers are only listed after 90 days without changes, are marked with their
  risk, and are always quarantined.
- Windows often does not record when a file was last opened, so "last opened" may show as
  unknown and is then never used as a reason.
- Caches of a running browser or app stay locked until the program is closed completely.
- Uninstalling keeps `%LOCALAPPDATA%\SafeSweep` (settings, history, logs and the quarantine),
  so nothing in the quarantine is lost. Delete that folder yourself when you no longer need it.
